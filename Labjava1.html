Lab Instructions

This lab will test your understanding of Java variables from Week 1. Complete each task by writing code in the editor. Click "Run Code" to test your solution.

Note: All your code should be written inside the main method.

Task 1: Variable Declaration

Declare the following variables with appropriate data types:

  • An integer variable named studentAge with value 20
  • A double variable named averageGrade with value 85.5
  • A boolean variable named isEnrolled with value true
  • A String variable named studentName with value "John Doe"
Hint: Remember to use the correct data types (int, double, boolean, String).

Task 2: Variable Operations

Create a program that calculates the area of a rectangle:

  1. Declare two integer variables: length (value 10) and width (value 5)
  2. Calculate the area (length × width) and store it in a new variable area
  3. Print the result using: System.out.println("Area: " + area);
Hint: The area should be 50 when you run the program.

Task 3: Type Conversion

Demonstrate type conversion between integers and doubles:

  1. Declare a double variable price with value 19.99
  2. Convert it to an integer and store in wholePrice (this will truncate the decimal)
  3. Print both values to see the difference
Hint: Use (int) for explicit type conversion.

Task 4: Constants

Create a program that calculates the circumference of a circle:

  1. Declare a constant PI with value 3.14159 (use the final keyword)
  2. Declare a double variable radius with value 5.0
  3. Calculate circumference (2 × PI × radius) and store in circumference
  4. Print the result
Hint: The formula for circumference is 2πr.

Task 5: Variable Scope

Demonstrate understanding of variable scope:

  1. Declare an integer variable count outside the main method (instance variable)
  2. Initialize it to 0 in the main method
  3. Create a block (using {}) inside main and declare another count variable there
  4. Print both variables to show they are different
Hint: The inner count shadows the outer one within its block.
