Week 3: Conditions and Control Flow in Java - Quiz

1. What is the correct syntax for an if statement in Java?

a) if condition { }
b) if (condition) { }
c) if: condition { }

Correct answer: b

2. What is the purpose of the else statement?

a) Executes when the condition is true
b) Always executes
c) Executes when the condition is false

Correct answer: c

3. Which of the following is a ternary operator in Java?

a) ? :
b) if-else
c) switch

Correct answer: a

4. What is the output of this code?
int age = 20;
if (age >= 18 && age < 30) { System.out.println("Young Adult"); }
else { System.out.println("Not a Young Adult"); }

a) Not a Young Adult
b) Young Adult
c) Compilation Error

Correct answer: b

5. What is the purpose of the break statement in a switch case?

a) Skips the next case
b) Continues execution to the next case
c) Exits the switch block

Correct answer: c
